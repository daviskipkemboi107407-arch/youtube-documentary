# Production Workflow
## Core Pipeline
Every documentary follows this general process:
1. Story Discovery
2. Story Evaluation
3. Research
4. Evidence Verification
5. Story Outline
6. Scriptwriting
7. Script Review
8. Narration
9. Visual Planning
10. Asset Collection or Creation
11. Video Editing
12. Sound Design
13. Quality Control
14. Thumbnail and Title
15. Upload
16. Performance Review
17. Workflow Improvement
## Principle
The first documentary should be produced with a largely manual workflow.
The purpose is to understand every stage before automating it.
Build → Test → Document → Improve → Automate
## Story Discovery
Generate and collect potential documentary ideas.
Do not immediately produce an idea.
Each idea should be evaluated for:
- Curiosity
- Evidence availability
- Narrative potential
- Originality
- Visual potential
- Audience appeal
- Production difficulty
## Research
Research the selected story using the research standards defined in RESEARCH_STANDARD.md.
Collect sources, claims, evidence, contradictions, and unresolved questions.
## Outline
Build the story structure before writing the full script.
The outline should establish:
- Opening hook
- Central question
- Context
- Key discoveries
- Evidence
- Competing explanations
- Escalation
- Resolution or remaining mystery
- Final takeaway
## Script
Write the narration from the verified research and approved outline.
The script should prioritize:
- Clarity
- Pacing
- Suspense
- Accuracy
- Natural narration
- Strong transitions
- Viewer curiosity
## Visual Planning
Every major section of the script should have an intentional visual approach.
Possible visual sources include:
- Historical photographs
- Maps
- Documents
- Scientific imagery
- Diagrams
- Archival footage
- Original graphics
- Animations
- Licensed stock footage
- Other legally usable assets
Visuals should support the story rather than exist merely to fill screen time.
## Editing
Combine narration, visuals, music, sound effects, graphics, and pacing into the final documentary.
The edit should serve the narrative.
## Quality Control
Before publishing, verify:
- Factual accuracy
- Source consistency
- Narration quality
- Audio levels
- Visual quality
- Copyright and licensing
- Spelling and on-screen text
- Pacing
- Title accuracy
- Thumbnail accuracy
## Publishing
Prepare:
- Title
- Thumbnail
- Description
- Chapters when appropriate
- Sources or references when appropriate
- Tags or metadata when useful
Publish manually during the first workflow.
## Post-Publication
Record relevant performance data and observations.
Study:
- Click-through rate
- Audience retention
- Average view duration
- Traffic sources
- Viewer feedback
- Strong and weak sections
Use these findings to improve the next documentary.
## Automation Strategy
Do not automate a process simply because it is possible.
Automate only after a process has been:
1. Performed manually
2. Understood
3. Documented
4. Repeated
5. Proven to benefit from automation
Automation must preserve:
- Research quality
- Accuracy
- Originality
- Storytelling
- Human creative judgment
