# Project Instructions
## Mission
Build a serious, original, faceless YouTube documentary business.
The immediate objective is to produce ONE excellent video from research through publication, learn and document the complete workflow, then progressively turn the proven workflow into a repeatable and eventually automated system.
## Content Direction
Primary areas:
- Artificial intelligence
- AI agents
- Coding and software
- Automation
- Technology
- Entrepreneurship
- Real experiments and projects
Content must prioritize originality, genuine usefulness, strong storytelling, and human-directed creative decisions.
Avoid mass-produced, low-effort, repetitive AI content.
## Operating Principle
Do not automate a process before understanding and validating it manually.
Build → test → document → improve → automate.
## Development Principles
- Prefer simple, maintainable solutions.
- Do not install dependencies without a reason.
- Protect storage and compute resources.
- Keep the project portable.
- Never expose secrets, API keys, passwords, or tokens.
- Verify before making destructive changes.
- Keep Git history clean and meaningful.
## Current Phase
EXECUTION.
Video #1 production is beginning. The foundation (structure, standards, workflows, documentation, and agent context) is established and will be validated through the first documentary.
## Device Strategy
The temporary Windows laptop is being used to establish and synchronize the foundation.
The primary development environment will later continue on a phone using Claude Code and Codex.
GitHub is the portable source of truth for project code and documentation.
## Future Direction
Once the first production workflow is proven, identify repetitive tasks and progressively introduce tools and agents for research, scripting, asset handling, production, publishing, analytics, and other operations.
Automation must support quality rather than replace judgment.
